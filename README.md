# Design Innovation Midterm Research Repo

## Structure
- `dmrc/01-dmrc-deep-dive.md` - DMRC base to indepth workings
- `isro/02-isro-deep-dive.md` - ISRO Space-as-a-Service base to indepth
- `boards/03-comparison-matrix.md` - ISRO vs DMRC vs UPI decision matrix
- `boards/04-visual-boards-plan.md` - 5-board plan for either topic + 2-day split

## How to use
1. Pick ONE topic using 03-comparison-matrix
2. Copy-paste respective deep-dive into Canva/Figma boards
3. Fieldwork: DMRC = shoot stations today. ISRO = download ISRO/NSIL/IN-SPACe brochures (free for education with credit)
4. Export PDF A3 landscape, 5 boards

Sources: delhimetrorail.com, isro.gov.in, nsilindia.co.in, inspace.gov.in, pib.gov.in, JICA, Hitachi DS24 case study. All govt images free for academic use with attribution.
