# Comparison - ISRO vs DMRC vs UPI for NIFT Jury

## Is it a service?
- ISRO YES: Use-oriented PSS. Pay for orbit, not rocket. Journey IDP>Authorize>Test>Contract>Launch>TT&C>Data. B2B invisible.
- DMRC YES: Civic physical service. Pay for punctual journey, not train. Journey Entry>Security>Tap>Wait>Ride>Interchange>Exit>Last-mile. Daily visible.
- UPI YES: Platform protocol. Pay/move money. Journey Link>Pay>PIN>Confirm. Mass invisible.

## Verdict
- Pick DMRC if you want safest win in Delhi: shoot Kashmere/Rajiv/Hauz Khas/New Delhi/INA today, blueprint tomorrow, 9/10 visual.
- Pick ISRO if you want stand-out tech-awe: only if you can defend service-design + show LEARN>FIX>FLY honesty (C61/C62), 10/10 uniqueness.
- Pick UPI only reframed as Zero-MDR Platform Economics, else skip.
- Hidden alt if both clash: India Post+IPPB (8/10 unique 9/10 ease, post office 1hr) or FASTag (9/10 unique 9/10 ease, toll/pump interview).
